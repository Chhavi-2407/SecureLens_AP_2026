SecureLens DBMS Benchmark
Query 02 — Scan history for a project
File: query_02_after.txt
Plan type: AFTER index creation
Index used: idx_scans_project_created (project_id, created_at DESC)

Benchmark query:
EXPLAIN (ANALYZE, BUFFERS, VERBOSE)
SELECT
    id, project_id, status, language, security_score,
    started_at, completed_at, created_at
FROM scans
WHERE project_id = '01180456-4514-4170-b1dd-ed9affba07ee'
ORDER BY created_at DESC;

Execution times:
Run 1: 0.153 ms
Run 2: 0.167 ms
Run 3: 0.102 ms
Average: 0.141 ms

Plan observations:
All three plans use Bitmap Index Scan on idx_scans_project_created,
followed by Bitmap Heap Scan and a separate Sort on scans.created_at DESC.
The index filters by project_id, but PostgreSQL still sorts the results.
